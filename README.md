# Smart Park Operations

智慧园区综合运营平台，包含 Go API、Vue 3 + TypeScript 前端、PostgreSQL、Redis、JWT、WebSocket、迁移种子和 OpenAPI 文档。

## Run

`go run ./...` starts the API on `:8080`. `cd frontend && npm install && npm run dev` starts the web console.

Business modules cover identity, parks, tenants, space booking, parking, visitors, work orders, inspections, energy, alerts, reports and audit logs.
